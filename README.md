# Premier Coaching and Training Center

Responsive static website with Bengali-first public pages, a demo admin dashboard, and a demo student portal.

## Pages

- Public website: `/`
- Admin demo: `/admin/`
- Student portal demo: `/student/`

## Vercel deployment

Import this repository into Vercel. The included `vercel.json` publishes the `website` directory without a build step.

This project currently contains UI demo data only. Authentication, databases, payments, and form submission are not connected to a backend service.
